# Glossary

- **Module**: one tool in the sidebar (for example YT-Music).
- **Queue**: the list of items on the YT-Music page.
- **Item**: one link in the queue.
- **Status**: Waiting, Downloading, Paused, Done, Failed.
- **Download folder**: the one folder all items save to.
- **Clear Finished**: removes Done items from the queue. Files stay.
